EQNX Sports Solutions — Cloudflare Pages Deploy

1) Create a new GitHub repo (public): eqnxsports-site
2) Upload all files from this folder to the repo (keep the folders 'assets/img' and 'assets/video').
   - Optional videos: put hero.mp4/webm and case-reel.mp4/webm in assets/video/
   - Poster image is already set: assets/img/fluid-bg.jpg
3) In Cloudflare: Pages → Create a project → Connect to GitHub → choose the repo
   - Build command: (leave empty)
   - Build output directory: /
4) After deploy: Pages → Custom domains → add eqnxsports.co.uk
5) Edit text later: open index.html on GitHub → "Edit this file" → change copy in sections About/Services/Contact → Commit.

Email CTA is linked to: contact@eqnxsports.co.uk

Company number and registered office appear in the footer & Privacy page.
